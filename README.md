# Premium Membership Bot v2
Render Web Service settings:
Build: `pip install -r requirements.txt`
Start: `python bot.py`

Environment variables:
BOT_TOKEN = new BotFather token
OWNER_ID = numeric Telegram user ID
UPI_ID = your UPI ID
PORT = 10000
DB_PATH = bot.db

QR codes are generated automatically from UPI_ID and the selected amount.
Do not put BOT_TOKEN in GitHub.
